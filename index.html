Кинотеатр ЛДС для Media Station X

Удобный просмотр фильмов и сериалов кинотеатра ЛДС на телевизорах Samsung, LG, Android TV и других. Работает только при подключении к интернету ЛДС.

Как подключить на телевизоре

  1. Установите приложение Media Station X из магазина приложений телевизора.
  2. Откройте его: Settings → Start Parameter → Setup.
  3. Введите адрес kumero96.github.io и подтвердите.
